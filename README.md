# BUYGEN

AI Agent prototype for autonomous commerce.

## Demonstrates

- Natural-language commerce goals
- Requirement extraction
- Product search
- Multi-factor comparison
- AI-style recommendation
- Human-in-the-loop approval
- Simulated purchasing
- Subscription monitoring
- Permission-based autonomy

## Architecture

User Goal
→ Agent
→ Search
→ Filter
→ Compare
→ Recommend
→ Permission Check
→ Action

This prototype intentionally uses simulated transactions. No real payments or purchases occur.
