BUYGEN VISUAL THEME

1. Copy the assets folder into:
   CommerceAgent/assets/

2. Copy buygen-visual-theme.css into:
   CommerceAgent/css/buygen-visual-theme.css

3. Add this to the HEAD of index.html:
   <link rel="stylesheet" href="css/buygen-visual-theme.css">

4. Home page wrapper/body:
   add class="home-page"

5. Search page wrapper/body:
   add class="search-page"

6. The old eye/face character selectors are disabled in this stylesheet.

The CSS uses:
- home-bg.gif = first reference
- search-bg.jpeg = second reference
- Bodoni Moda = elegant Fate-style overall serif
- DM Sans = readable controls/body
- decorative display styling for search/results
